# CloakForge — Audit Summary

**Verdict: NOT ready for production yet.** No wallet-drain or key-theft risk was found — the non-custodial design holds (fee wallet is server-only, fees recomputed server-side, private RPC never leaks, no XSS sinks). The issues found are fixable: placeholder legal data that is already live, one critical framework CVE, debug routes in prod, two amount-scaling bugs that can move far more tokens than intended, fees that fail open, no rate limiting, and missing consumer/sanctions terms.

## P1 — Within first weeks

- **Security headers** — `headers()` in `next.config.ts`: CSP (Report-Only first), `frame-ancestors 'none'`, nosniff, Referrer-Policy, Permissions-Policy, HSTS `includeSubDomains; preload`, `poweredByHeader: false`.
- **Coupons** — enforce usage limit server-side at tx-build time; 10+ char random codes; throttle validate.
- **Admin API** — signed message needs nonce + expiry + domain; use a dedicated admin wallet, not the fee wallet.
- **SSRF** — metadata URI fetch: https only, block private IPs, size/time caps, ignore client `includeImages`.
- **Liquidity tool** — shows 0.1 SOL fee but never charges it; CLMM opens at `minPrice`, slippage ignored.
- **Client tx check** — verify program IDs, fee payer, amounts before asking the wallet to sign.
- **Token creator** — MetadataPointer authority stays with creator → "immutable metadata" bypassable.
- **Errors** — return 400 (not 500 + parser text) for bad JSON; generic messages for non-`AppError`.
- **Revalidate webhook** — secret in header, constant-time compare, remove GET.
- **CI** — `pull_request` trigger, add `tsc`/build/audit, pin Actions to SHA, Dependabot, Node 24 (`@solana-program/*` requires it).
- **Ops** — error monitoring (`onRequestError` + Vercel log drain), `security.txt`, noindex on `/admin` `/account`, fix build on empty blog.

## Legal — bottom line

- **MiCA / AML / US money-transmission law: low risk** — non-custodial, unsigned-tx builder, no custody or exchange.
- **Sanctions: highest risk** — no geo-blocking or wallet screening; US hosting (Vercel iad1, Alchemy) gives OFAC jurisdiction.
- **Consumer law: real exposure** — without a valid waiver, EU users can claim fee refunds for 14 days, extendable to 12 months.
- **Branding** — "Cloak" + "anonymous / No KYC" copy is avoidable risk post Tornado Cash/Samourai; no mixing feature exists — reword marketing.
- **Not legal advice.** Have a Czech advokát review `04-legal-compliance.mdx` (open questions flagged there).
