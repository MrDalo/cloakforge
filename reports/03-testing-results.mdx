## Dependencies and CVEs

Versions installed: `next 16.2.10`, `react 19.2.4`, `react-dom 19.2.4`.

**Next.js.** `npm audit` reports 18 advisories against `16.2.10`, with fixes up to `16.3.8`:

- Critical: GHSA-2xp9-vwfh-vxw4 (AVIF image-optimizer RCE), GHSA-vcvr-r3jv-pc5j (`next/og` RCE) and GHSA-p293-qw3h-jr36 (Windows-only RCE).
- High: middleware/proxy bypass, Server Action DoS, three SSRF issues (Server Actions, rewrites, Image Optimization) and cache confusion or poisoning.

The Next.js blog also lists an out-of-band release on 2026-10-14, which ships as **`16.4.1`**. It covers RCE in `use cache` and in SVG image optimization, plus React Server Components patches (`react` `19.2.9` line). **Upgrade target: `next@16.4.1`, and bump `react`/`react-dom` to the patched `19.2.x`.** Vercel hosting may mitigate some issues, such as the Windows RCE and the platform image optimizer, but the upgrade is still required.

## Owner-run live checks

Run these from a normal network. They are non-destructive, but keep the request counts small.

```bash
# 1. Header check (root + one API route)
curl -sI https://www.cloakforge.app/ | grep -iE 'content-security|strict-transport|x-frame|x-content-type|referrer|permissions|x-powered'
curl -sI https://www.cloakforge.app/api/solana/price

# 2. Graded header scans
open "https://securityheaders.com/?q=https://www.cloakforge.app&followRedirects=on"
open "https://developer.mozilla.org/en-US/observatory/analyze?host=www.cloakforge.app"

# 3. One malformed POST per API route (expect 400, never 500 or a stack trace)
for r in solana/burn-tokens solana/token-creator solana/wallet-tokens discount-coupon/validate log test/create-transaction; do
  printf '%s ' "$r"; curl -s -o /dev/null -w '%{http_code}\n' -X POST -H 'content-type: application/json' --data '{"a":' "https://www.cloakforge.app/api/$r"
done
curl -s -o /dev/null -w 'ipfs auth: %{http_code}\n' -X POST https://www.cloakforge.app/api/ipfs/upload-file   # expect 401

# 4. Rate-limit check (15 requests each; look for any 429)
for i in $(seq 15); do curl -s -o /dev/null -w '%{http_code} ' -X POST -H 'content-type: application/json' --data "{\"couponCode\":\"Q$RANDOM\"}" https://www.cloakforge.app/api/discount-coupon/validate; done; echo
for i in $(seq 15); do curl -s -o /dev/null -w '%{http_code} ' https://www.cloakforge.app/api/solana/price; done; echo

# 5. Passive DAST and Lighthouse sweep
docker run --rm -t ghcr.io/zaproxy/zaproxy:stable zap-baseline.py -t https://www.cloakforge.app
npx unlighthouse --site https://www.cloakforge.app
```
